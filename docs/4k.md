# Protocol: 4k

> **Extracted from Launcher JS only; NOT verified on hardware — confirm with
> usbmon before trusting writes.**

Runtime-detected variant `info.protocol === "4k"`. Wireless 4K mice (Keychron
M3/M4/M6 4K family, VID `0x3434`). Product table from receiver class `Ot`:

| productName | productID | PID |
|---|---|---|
| M6 4K | 0x0624 | 0xD046 |
| M3mini4K (alu) | 0x0622 | 0xd041 |
| M3M24k | 0x0623 | 0xd045 |
| M3mini4K | 0x0620 | 0xd037 |
| M44K | 0x0621 | 0xd040 |
| M34K | 0x07a0 | 0xd03c |

## Transport

All 4k mouse config rides the **long 64-byte channel, HID report id `0`**
(`write(0, buf)`), `buf` is `Uint8Array(64)`. Frame layout is the NAPE-style
group: `buf[0]=command`, `buf[2]=subgroup/length`, `buf[3]=action`, payload from
`buf[4]`, `buf[63]=checksum`.

| Report ID | Dir | Bytes | Role |
|---|---|---|---|
| `0` | OUT | 64 | command frame (`write(0, buf)`) |
| — | IN | 64 | reply, matched on `buf[0]`/`buf[3]` filters |
| `81` (0x51) | OUT | 20 | legacy short read used only by the 1k `Ee`/`zt` classes, **not** by 4k |
| `181` (0xB5) | OUT | 20 | **8k short channel — NOT used by any 4k class** (used only by 8k `io/ms/li/Vt/Ai/Hn` siblings) |

- **No short-channel (181) writes exist in the 4k path.** Every 4k class writes
  report id `0`. The `181` builders in the bundle belong to the 8k/nordic
  sibling classes selected by other `case` arms.
- The `0xA7`=167 NAPE builders live in a separate VIA/QMK keyboard-matrix module
  (single-letter classes, offset ~1.80M) and are **not reachable** from the 4k
  mouse dispatch.

### Checksum (`$e` / `setbuf63`)

64-byte frames: `buf[63] = 161 - (sum(buf[0..62]) & 0xFF)` (seed `0xA1`).
Applied right before every `write(0, …)`.

### Work-mode bit (`Ae`)

`Ae(buf, workMode)`: if `workMode === 1` (wireless/dongle) then
`buf[0] |= 1 << 6` (adds `0x40`/64). This is why every reply filter accepts
**both** the raw command byte and command+64:
- read `4` ⇒ accept `buf[0]===4 || buf[0]===68`
- read `0` ⇒ accept `0 || 64`; read `1` ⇒ `1 || 65`; read `3` ⇒ `3 || 67`;
  read `2` ⇒ `2 || 66`; read `7` ⇒ `7 || 71`; read `9` ⇒ `9 || 73`;
  read `10` ⇒ `10 || 74`.

LE16 helper `numToHighLow(v, 2, 8, "LowToHigh")` ⇒ `[v&0xFF, v>>8&0xFF]`.

## READ — main settings block (class `Kt`, cmd `0x04`)

Request: `buf[0]=4, buf[2]=129, buf[3]=1` → `Ae` → `$e` → `write(0)`.
Reply filter: `(b[0]===4 || b[0]===68) && b[3]===1`. Field map (`b[]`=reply):

| Field | Offset / formula | Notes |
|---|---|---|
| dpi.level | `[b[7], b[7], b[7]]` | active DPI index (same for X/Y/all) |
| dpi.levelsVal[5] | LE16 @ `b[8],b[12],b[16],b[20],b[24]` | preset DPI values |
| dpi.levelNum | `popcount(b[6])` | number of active presets |
| sysFeatures.lod | `b[43]` | lift-off distance |
| sysFeatures.wave | `b[4]>>4 & 1` | ripple control |
| sysFeatures.line | `b[4] & 1` | angle straightening |
| sysFeatures.motion | `b[4]>>5 & 1` | motion sync |
| sysFeatures.scrollDir | `b[4]>>7 & 1` | invert scroll |
| sysFeatures.angle | `0` | hard-coded; angle snap unsupported on 4k |
| debounce.value | `b[54]` | ms |
| sleep.time | `b[53]<<8 \| b[52]` | LE16 idle sleep |
| pollingRate.level | `b[5]>1 ? b[5]-1 : 0` (×3) | rate code, biased by +1 in frame |
| pollingRate.levelsVal | `[0,1,2,3,4,5]` | fixed code list |
| pollingRate.levelNum | from `getPower().reportRateMax` | |
| support.* | all `false` except `loopDPressSupport` | 4k advertises minimal support flags |

`support = {MaxAndStep:false, pollingGears:false, profile:false, scroll:false,
debounce:false, rouseOrigin:false, sleep:false, fps20k:false,
loopDPress:b.loopDPressSupport, pairKey:false, quickResp:false,
profileSelect:false, angle:false}`.

Composition: `Kt.get()` issues the `0x04` read, then chains `qe.get()`
(version), `getPower()` (battery+profile), and (wireless) `Ot.get()`
(vid/pid/receiver) before emitting the merged config.

## READ — power / profile / report-rate (class `Kt.getPower`, cmd `0x01`)

Request: `buf[0]=1, buf[2]=129, buf[3]=1`.
Reply filter: `(workMode? b[0]===65 : b[0]===1) && b[3]===1`.

| Field | Offset |
|---|---|
| profile.current | `b[7]` |
| power.state | `b[5]` |
| power.value (battery %) | `b[6]` |
| reportRateMax | `b[10]` |

Default on error: `{profile:0, power:{state:0,value:0}, reportRateMax:3}`.

## READ — version (class `Ke`, cmd `0x00`)

Request: `buf[0]=0, buf[2]=129, buf[3]=0`. Reply `(0||64)===b[0] && b[3]===0`.
`version = "${b[9]}.${(b[8]&240)>>4}.${b[8]&15}"`.
(`qe` class is identical and is the one wired into the dispatch for version /
dongle version.)

## READ — receiver / vid-pid (class `Ot`, cmd `0x40`)

Request: `buf[0]=64, buf[2]=129, buf[3]=0`, checksum
`buf[63]=161-(buf[0]+buf[2]+buf[3])`. Reply `b[0]===64 && b[3]===0`.
`productID = "0x" + hex(b[5]) + hex(b[4])`, looked up in the product table for
PID; `receiver.state = b[6]`; vpId = vendorProductId(0x3434, PID).

## READ — buttons / keymap (class `bn`, cmd `0x03`)

- **getAll** `buf[0]=3, buf[2]=129, buf[3]=1`. Reply `(3||67)===b[0] && b[3]===1`.
  Each button `i`'s 4-byte record at `b[4 + 4*i .. +3]`, decoded by
  `getMouseButtonInfo` (mouse / disable / dpi / media / light / shortcut /
  keyboard / game / macro). Macro record: `rec[0]===9` ⇒ macro index `rec[2]`.
- **get(i)** single button: `buf[0]=3, buf[2]=130, buf[3]=3, buf[4]=i&0xFF`.
  Reply `(3||67)===b[0] && b[3]===3 && b[4]===i`; record at `b[5..8]`.

## READ — pair-key / loop-D-press combo (class `oo.get`, cmd `0x04`)

Request: `buf[0]=4, buf[2]=129, buf[3]=1` (re-uses the main read). Parses:
- if `b[49]===0`: defaults `pairKey = left1/mid0/right0/fwd1/back0`, `time=b[50]`
- else bitmask `b[49]`: left=`&1`, middle=`>>1&1`, right=`>>2&1`, forward=`>>3&1`,
  backward=`>>4&1`; `time = b[50]`.

## WRITE — settings frame (cmd `0x04`, `buf[2]=181`, `buf[3]=2`)

DPI, polling rate, sensor/LOD/scroll, debounce and sleep all share **one**
64-byte frame. The four setter classes (`xo`, `Ps`, `Pt`, `Zn`) build the *same*
frame from `baseInfo`, each overriding only the field it changes, then wait for
reply `(4||68)===b[0] && b[3]===2` and call `rt.set()` (save). Frame layout:

| Index | Value |
|---|---|
| `[0]` | `4` |
| `[2]` | `181` |
| `[3]` | `2` |
| `[4]` | sysFeatures bitmask: `line<<0 \| wave<<4 \| motion<<5 \| scrollDir<<7` |
| `[5]` | polling: `level>0 ? level+1 : 0` |
| `[6]` | dpi count mask `[1,3,7,15,31][levelNum-1]` |
| `[7]` | active dpi level index |
| `[8..]` | 5 DPI presets, each LE16 written **twice** (X then Y): `lo,hi,lo,hi` per level → 20 bytes ending at `[27]` |
| `[43]` | LOD |
| `[50],[51]` | sleep.time LE16 |
| `[52],[53]` | sleep.time LE16 (repeated) |
| `[54]` | debounce value |

Per-class override (everything else taken from `baseInfo` snapshot):

| class | dispatch feature | overrides |
|---|---|---|
| `xo` | **DPI** | `[5]`=arg.pollLevel+1, `[7]`=arg.level, `[8..]`=arg.levelsVal, `[43]`=lod |
| `Ps` | **polling rate** | `[5]`=arg.level+1 |
| `Pt` | **debounce** | `[54]`=arg (debounce value) |
| `Zn` | **sensor / LOD / scroll** | `[4]` from `arg.sensor[]` (line=`sensor[1]`, wave=`sensor[0]`, motion=`sensor[2]`, scrollDir=`arg.scrollDir`), `[43]`=arg.lod |

`Br.setAngle` is a no-op (`case"4k":break`) — **angle snap unsupported on 4k**.

## WRITE — profile select (class `hn`, cmd `0x02`)

`buf[0]=2, buf[2]=130, buf[3]=1, buf[4]=profile`. Reply `(2||66)===b[0] && b[3]===1`.

## WRITE — pair-key / combo (class `oo.set`, cmd `0x04` then `0x0A`)

Read-modify-write: issue main read (`[0]=4,[2]=129,[3]=1`), on reply set
`reply[3]=2, reply[49]=mask`, `setbuf0`/`setbuf63`, `write(0)`, then `saveData`
(`buf[0]=10, buf[2]=129, buf[3]=1`). `setbuf0` applies the same `|=workMode<<6`,
`setbuf63` the same `161-sum` checksum.

## WRITE — button keymap assign (class `Ci`, cmd `0x03`)

`buf[0]=3, buf[2]=128 | (payload.length+1), buf[3]=4, buf[4]=buttonIndex,
buf[5..]=payload`. Reply `(3||67)===b[0] && b[3]===4`, then `rt.set()` save.
Payload built per assignment type (`set(funType, index, bytes)`):

| method | funType | payload bytes |
|---|---|---|
| basic | Mouse | `numToHighLow(code,4,8,HighToLow)` |
| keyboard | Keyboard | `[0, modMask, keycode, 0]` |
| media | Media | `numToHighLow(code,4,8,HighToLow)` |
| dpi | Dpi | `numToHighLow(code,4,8,HighToLow)` |
| pollingRate | PollingRate | `numToHighLow(code,4,8,HighToLow)` |
| game | Game | `[16/48+floor(n/255), key, count, rate]` |
| shortCut | ShortCut | `numToHighLow(code,4,8,HighToLow)` |
| profile | Profile | `[idx]` |
| disable | Disable | `[0,0,0,0]` |
| remove | Remove | (none) |

## WRITE — macro (class `ur`, cmd `0x07` + bind `0x03`)

Multi-frame upload of `macro` (array flattened, 4 bytes per event):

First frame: `buf[0]=7, buf[3]=2, buf[4]=index, buf[5]=loopMode, buf[6]=loopNum,
buf[41]=delay&0xFF, buf[42]=delay>>8, buf[43]=eventCount&0xFF,
buf[44]=eventCount>>8`, payload from `buf[45]`.
Continuation frames: `buf[0]=7, buf[3]=2, buf[4]=index`, payload from `buf[5]`.
`buf[1]=frameSeq`; `buf[2]` length/flag:
`qt<18 ? 128|(42+qt) : (more? 188 : 128|(chunkLen+2))`.
Reply `(7||71)===b[0]` between frames.

After upload, bind macro to the button via `setMouseMacro(idx,idx)`:
`buf[0]=3, buf[2]=136, buf[3]=4, buf[4]=button, buf[5]=9, buf[6]=1, buf[7]=macro,
buf[8]=0` → then `rt.set()` save.

## WRITE — factory reset (class `hr`, cmd `0x09`)

`hr.set(opts, scope="all")`: if `opts.dpi` ⇒ `setDpiProfile([5,6,7])`
(loops `setBasic({dpi:n},1)` per index with 1s spacing); else `setBasic`.

`setBasic(opts, scope)` frame:
`buf[0]=9, buf[2]= scope!="all"?130:129, buf[3]= scope!="all"?flags : (opts?255:0),
buf[4]=dpiVal`. Flags resolution:
- `opts.all` ⇒ `flags=255, buf[4]=255`
- `opts.key` ⇒ `flags=2, buf[4]=255`
- `opts.dpi` ⇒ `flags=3, buf[4]=opts.dpi`

Reply `(9||73)===b[0] && (!opts.dpi || b[4]===opts.dpi)`, debounced 500ms, up to
3 retries; then `rt.set()` save.

## SAVE / commit (class `ut`, cmd `0x0A`)

`buf[0]=10, buf[2]=129, buf[3]=1` → `Ae` → `$e` → `write(0)`.
Reply `b[0]===10 || b[0]===74`. Invoked by `rt.set()` after most writes
(`rt` dispatches `4k`/`8k_nordic` → `ut.set()`).

## Live monitor (class `yn.open`)

Passive: subscribes to `report$`, no write. Emits `monitor-base` on frames where
`(b[0]===1 || b[0]===65) && (b[2]===140 || b[2]===142) && b[3]===1`:
`power={state:b[5],value:b[6]}, dpi.level=b[8], pollingRate.level=b[9]>0?b[9]-1:b[9]`.

## Unsupported on 4k (explicit `console.warn` / no-op branches)

- Light/RGB config — get & set: "4k 暂不支持灯光配置".
- Explicit save command — "4k 不需要保存配置指令" (save is folded into `rt.set`).
- Angle snap (`setAngle`) — `break` (no frame sent).
- `setSensorParams` / `setSystemParams` — `default:return` (no 4k frame).
- A further get/set pair — "4k 暂不支持此配置".
